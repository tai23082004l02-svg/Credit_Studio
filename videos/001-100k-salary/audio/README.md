# Tải giọng đọc vào đây

Video: **Why You Feel Broke on a $100,000 Salary**.

## Cách tải lên GitHub

1. Ở thư mục này, chọn **Add file → Upload files**.
2. Kéo tệp MP3 hoặc WAV vào trang.
3. Chọn **Commit changes**, lưu vào nhánh `main`.
4. Báo lại trong cuộc trò chuyện khi đã tải xong.

## Tệp cần gửi

- Ưu tiên một tệp giọng đọc liền mạch: `voiceover-en-v01.mp3`.
- Có thể gửi WAV nếu dung lượng phù hợp.
- Nếu tạo riêng từng đoạn: `01-hook.mp3`, `02-take-home-pay.mp3`, `03-fixed-costs.mp3`, `04-irregular-expenses.mp3`, `05-lifestyle-creep.mp3`, `06-social-comparison.mp3`, `07-action-plan.mp3`, `08-ending.mp3`.
- Giữ khoảng nghỉ tự nhiên, không đọc tiêu đề, không ghép nhạc vào giọng chính.
- Nếu sửa bản đọc, tăng phiên bản, ví dụ `voiceover-en-v02.mp3`.

GitHub giới hạn tải lên qua trình duyệt ở 25 MiB mỗi tệp. Nếu WAV quá lớn, xuất MP3 hoặc chia theo 8 đoạn phía trên. Không cần đổi đuôi WAV thành MP3; hãy xuất đúng định dạng từ công cụ âm thanh.

Kho GitHub hiện công khai: tệp tải vào đây cũng công khai.
Thư mục này là nơi bàn giao audio, không tự thêm nhạc hay giọng đọc vào ứng dụng.
