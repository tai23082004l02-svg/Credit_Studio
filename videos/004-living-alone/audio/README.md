# Âm thanh — Living Alone

Sau khi thống nhất lời thoại, tải WAV/MP3 gốc vào thư mục này trên nhánh `main`. Tên gợi ý: `living-alone-voiceover.wav`.

Đọc nội dung `../narration.txt`, giọng Anh Mỹ tự nhiên; không đọc tiêu đề, nguồn hoặc hướng dẫn tiếng Việt. Giữ các con số và mốc năm trong lời đọc. Chưa cần ghép nhạc nền. Giữ bản gốc; nếu có lần thu mới, dùng tên phiên bản riêng.

Giới hạn upload tệp đính kèm của Studio là 25 MiB/tệp; nếu tệp lớn hơn, bàn giao qua repo bằng Git hoặc phương thức upload GitHub hỗ trợ kích thước đó. Việc upload không tự dựng video.
